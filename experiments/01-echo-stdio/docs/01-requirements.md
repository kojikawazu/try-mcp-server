# MCP サーバー要件定義 (TypeScript/Node.js)

## 目的

TypeScript/Node.js で最小構成の MCP サーバーを実装し、ローカルで起動して MCP クライアントから試験利用できる状態にする。

## 対象範囲

- ローカル開発のみ（ホスティング/認証は対象外）。
- 例示用のツール 1 件とリソース 1 件を用意する。
- 実行手順と設定方法を明確にする。

## 機能要件

- TypeScript で MCP サーバーのエントリポイントを用意する。
- 最低限、次の 2 つを公開する。
  - ツール 1 件（例: `echo` または `hello`）。
  - リソース 1 件（例: `example://readme`）。
- 環境変数から設定を受け取る。
  - `MCP_SERVER_NAME`（デフォルト: `try-mcp-server`）。
  - `MCP_SERVER_PORT`（デフォルト: `3005`）。
- リクエストの基本的なライフサイクルを stdout にログ出力する。

## 非機能要件

- Node.js LTS 互換の実行環境で動作する。
- TypeScript の strict チェックを有効にする。
- 依存関係を最小限にし、ドキュメント化する。
- 再現可能なローカルセットアップ手順を提供する。

## 成果物

- `docs/01-requirements.md`（本ドキュメント）。

- 利用方法を示す最小 README。
